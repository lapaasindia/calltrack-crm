One-time setup — how should this computer be used?
This computer runs the CallTrack background service. Choose "main computer" to open it — the app will attach to the service; restoring a backup here is done in the service's data folder, not from this screen.
First login: admin / admin123 — change it in Settings. Daily backups are saved on this computer (menu: Server → Open Backups Folder). Nothing ever goes to the internet.
Find it on the main computer: open CallTrack there → menu Server → Connection Info. Both computers must be on the same office network.
